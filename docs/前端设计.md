# 智能简历筛选系统 — 前端设计（低保真 v1）

> 脚手架：**Ant Design Pro**（React + AntD，ProLayout / ProTable / ProForm / access 权限）。
> 后端：Django + DRF。本稿为线框级，用于对齐信息架构与关键交互，视觉细节后续再定。

┌ 处理范围: 导入时间[范围] 状态[待处理 ▾]    （作用于数据池的筛选条件）

│ Step2 岗位分类        (·)规则 ( )AI [运行]  ◐ 运行中 60%   │

### 7) 系统设置
- **配置项**：分配倍数、南北省份字典（省份→南/北，表格 CRUD）、W3 认证开关。
- **用户权限**：用户列表 + 角色（HR / 接口人 / 管理员），RBAC。

## 三、角色与可见性（Ant Design Pro access）

| 菜单 | HR / 管理员 | 接口人 |
|------|------------|--------|
| 数据导入 / 简历库 / 岗位 / 院校 / 部门 | ✓ | �—（只读或不可见，待定）|
| 处理流水线 / 各步结果 | ✓ | ✗ |
| 分配结果 / 下发 | ✓ | ✗ |
| 我的待领取 / 我的已领取 | — | ✓（仅本部门）|
| 系统设置 | ✓（管理员）| ✗ |

> 接口人登录后默认落到「我的待领取」。具体接口人能看到哪些数据，取决于待确认的角色边界。
